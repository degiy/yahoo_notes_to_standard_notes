# y2std.pl

a perl script to convert notes from https://calendar.yahoo.com/?view=notepad to https://app.standardnotes.com/ using only basic txt (no fee from std notes)

You will loose info (all html stuff, colors,...)

But you will keep your text and folders (that will become tags)

HTML=>TXT translation is made through *w3m*, you will need to install it before running the script
